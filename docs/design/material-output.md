# material-output — マテリアルの出力と 3D ビュー

作成日時: 2026-11-22 21:46
更新日時: 2026-11-22 21:46

## Material Output ノード（`io.material`）

マテリアルの出力は、**1 つのノードにマップごとの入力ピンを並べる**形にする。
マップの名前と並びは Megascans に合わせる。

| ピン | 番号 | 型 | 繋いでいないとき | 内容 |
| --- | --- | --- | --- | --- |
| Albedo | 0 | Color | 0.5 のグレー | 表示色（sRGB の値）。ライティングを含まない色 |
| Normal | 1 | Color | 平ら | タンジェント空間の法線。向きはパラメータ「法線の形式」 |
| Roughness | 2 | Gray | 0.5 | 0 で鏡面、1 で粗い |
| Metalness | 3 | Gray | 0 | 0 で非金属、1 で金属 |
| AO | 4 | Gray | 1 | 1 で遮蔽なし |
| Displacement | 5 | Gray | 視差なし | 高さ。**0.5 が基準面** |
| Opacity | 6 | Gray | 1 | 1 で不透明 |

- ピンの番号は `graph::MaterialChannel` と同じ。保存形式ではピンを名前で持つので、後ろへ足すぶんには互換が保てる。
- パラメータは「法線の形式」（DirectX / OpenGL、既定は DirectX）だけ。3D ビューはこれに従って法線を読む。
  `Height to Normal` の「形式」と揃えること。
- ノード自身の出力は Albedo の写しで、サムネイル用にだけ持つ（出力ピンは UI に出さない）。
- グラフに複数置いた場合、3D ビューは**最初の 1 つ**を使う。

### Megascans に合わせた点と、決めきれていない点

- マップ名（Albedo / Normal / Roughness / Metalness / AO / Displacement / Opacity）と、
  Displacement の基準面 0.5 は Megascans に合わせた。
- **法線の向き**は、Megascans の公式資料で確認できていない。フォーラムでは DirectX（緑が下向き）と
  されているので既定を DirectX にし、パラメータで切り替えられるようにした。実際の Megascans の素材と
  並べて確かめたら、この節を更新する。
- Megascans にある Gloss / Specular / Cavity / Translucency / Fuzz / Bump は入れていない。
  メタリック・ラフネスのワークフローでは Roughness と Metalness があれば足りるため。必要になったら
  入力を足す（入力は 8 本まで。いま 7 本）。

以前の `io.output`（用途タグ付きの出力を用途ごとに置く形）は廃止した。

## 3D ビュー

Material Output に繋がったマップを、球か平面に貼って描く。描画は
`src/engine/MaterialPreview.cpp` と `shaders/preview/material_preview.hlsl`。

- **描き方**: メッシュを使わず、コンピュートシェーダーでピクセルごとに視線と球 / 平面を交差させる。
  評価エンジンと同じコンピュートの仕組みだけで済み、グラフィックスパイプラインを持たずに済む。
- **シェーディング**: Cook-Torrance（GGX / Smith / Schlick）のメタリック・ラフネス。
  Albedo は sRGB → リニアに直してから使う。F0 は非金属 0.04、金属は Albedo。
- **ライト**: 太陽（平行光）1 つ + 環境光。
- **環境**: 手続きで作った空（天頂・地平線・地面のグラデーションと太陽のまわりの明るみ）。
  鏡面は反射方向の空を粗さに応じてぼかし、環境 BRDF は Karis の近似式を使う。
  **HDRI の IBL（事前フィルタしたキューブマップ + BRDF LUT）はまだ無い。**
- **高さ**: パララックスオクルージョン（32 段）。輪郭は変わらない。
- **不透明度**: 背景と混ぜるだけ（裏側の面は描かない）。
- **トーンマップ**: ACES（Hill のフィット）→ sRGB。
- **UV**: 平面はタイルを「タイル」の数だけ繰り返す。球は経度 × 緯度で、横に 2 倍の数を貼る
  （極で詰まるのは避けられない）。

### 操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ | 視点を回す |
| Shift + ドラッグ | ライトを回す |
| ホイール | 近づく / 離れる |
| 「表示設定」 | タイル、視差の高さ、露出、ライト、環境光、空の表示 |

### 既知の制限

- テクスチャにミップが無いので、離れると細かい模様がちらつく。
- 影（セルフシャドウ）は無い。溝の暗さは AO と視差で出している。
- キューブ・円柱・任意の OBJ、AgX、テッセレーションによる変位は未対応。
- 表示設定は保存されない（起動のたびに既定値に戻る）。
