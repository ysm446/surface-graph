# design-guide — UI の設計ガイド

作成日時: 2026-11-22 20:28
更新日時: 2026-11-22 20:28

UI は姉妹プロジェクト terrain-graph に合わせる。配色・部品・寸法は `src/ui/UiStyle.h` を共有しており、
規約の本体は terrain-graph の `docs/design/design-guide.md` にある。ここには、このプロジェクトで
守ることと、このプロジェクト固有の決まりを書く。

## 基本

- 設定値は `ui::Property*` のヘルパーで「ラベル：値」の行として描く。`ImGui::SliderFloat` などを直接呼ばない。
  行は `ui::BeginPropertyTable` の中に置き、見出しは `ui::SectionHeader`（テーブルの外）。
- 色を直書きしない。配色は `ui::ApplyTheme()` に集約する。例外は、ピンの型の色やノードのカテゴリの印の
  ような**意味を持つ色**だけ（`src/app/GraphPanel.cpp` の先頭にまとめてある）。
- アクセントは 1 色（`#96A3AD`）。選択の枠、変更の印に使う。
- 画面に出す文字は `ui::Tr("日本語", "English")` で両方書く。ノード名・ピンの型・チャンネル名のように
  英語のほうが通じる語は訳さない。
- 変わらない説明は「?」（`ui::SectionHeader(label, help)` / `ui::HelpMarker`）とツールチップへ。
  `ui::HintText` は「いまの状態」（選んでいない、空、など）にだけ使う。
- 文字が入る寸法は `ui::TextScaled()`、それ以外は `ui::Scaled()`。

## ウィンドウとレイアウト

- ウィンドウ名は `"表示名###固定ID"`。DockBuilder からは `"###固定ID"` で引く。

  | パネル | 固定 ID | 既定の位置 |
  | --- | --- | --- |
  | 2D ビュー | `###View2D` | 上 |
  | グラフ | `###Graph` | 中央 |
  | パラメータ | `###Parameters` | 右 |
  | グラフ設定 | `###GraphSettings` | 右（タブ） |

- ドックスペースの名前（`SurfaceGraphDockSpace_vN`）は、パネルを足したり外したりしたら版を上げる。
- 既定のレイアウトは「ウィンドウ > レイアウトを初期化」で組み直せる。
- ステータスバーは下端。解像度、ノード数、VRAM、GPU 時間、評価の状態、直近のログを出す。
  情報は 6 秒で消え、警告とエラーは次のメッセージまで残る。
- メニューは要求を積むだけにして、GPU の待機やグラフの差し替えはフレームの先頭で行う。
  ショートカットは必ずメニューにも表示する。

## グラフのパネル

- ノード: 背景 `(0.15, 0.15, 0.15)`、角丸 6、余白 12 / 10。見出しにカテゴリの色の小さな四角と名前、
  その下にサムネイル（`ui::kNodeThumbnail` = 96）、その下にピンの行。
- ピン: 丸をノードの縁に置く（半分が外へ出る）。リンクの端は丸の中心。繋がっていれば塗り、
  いなければ輪。ラベルも掴める範囲に含める。
- ピンの型の色: Gray = 灰、Color = 黄、Value = 青（彩度は抑える）。リンクも繋ぎ元の型の色。
- 枠: 選択はアクセント色、2D ビューに出しているノードは薄い黄緑、エラーは赤（太さ 2）。
- 背景は点の格子。拡大率に合わせて間引く。
- ノードの位置はグラフモデルが持つ。エディタの表示位置と拡大率は保存しない。

## 操作

| 操作 | 動作 |
| --- | --- |
| 空白で右クリック / Tab | 検索付きのノード追加メニュー |
| リンクを空白にドロップ | そのピンに繋げるノードだけのメニュー。選ぶと自動で繋がる |
| Delete | 選んだノード / リンクを消す |
| Ctrl+C / Ctrl+V / Ctrl+D | コピー / 貼り付け / 複製（クリップボードには JSON） |
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） | 元に戻す / やり直す |
| ノードをダブルクリック | 2D ビューに表示（ピン留め中でも） |
| A | グラフ全体を表示 |
| 中ボタンドラッグ / ホイール | キャンバスの移動 / 拡大縮小 |
| パラメータの行で右クリック | グラフ入力として公開 |
| スライダーを Ctrl+クリック | 値を直接入力 |

ショートカットは、キャンバスに載っていて文字入力中でないときだけ効く。

## アンドゥ

- グラフ全体のスナップショットを積む（最大 100 手）。
- 同じ部品を掴み続けている間（スライダーのドラッグ）は 1 手にまとめる。
- **ノードの移動はアンドゥの対象にしない。** 位置は保存されるが、元に戻す対象にはならない。

## 確認のしかた

UI を変えたら、スクリーンショットを 1 枚撮って目で見る。

```
build/bin/Debug/surface_graph.exe --open graphs/brick.sgraph --screenshot-ui data/screenshots/editor.png --screenshot-frame 40 --select-node 2
```

- `--screenshot-ui` はバックバッファを読み戻すので、ウィンドウが隠れていても欠けない。
  評価が終わるまで待ってから撮り、撮ったら終了する。
- `--select-node <id>` で、撮る前に選ぶノードを指定できる。
- マウス操作を伴う変更は、スクリーンショットでは確かめられない。確かめていないときは、そう報告する。
