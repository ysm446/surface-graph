# design-guide — UI の設計ガイド

作成日時: 2026-11-22 20:28
更新日時: 2026-11-26 12:40

UI は姉妹プロジェクト terrain-graph に合わせる。配色・部品・寸法は `src/ui/UiStyle.h` を共有しており、
規約の本体は terrain-graph の `docs/design/design-guide.md` にある。ここには、このプロジェクトで
守ることと、このプロジェクト固有の決まりを書く。

## 基本

- 設定値は `ui::Property*` のヘルパーで「ラベル：値」の行として描く。`ImGui::SliderFloat` などを直接呼ばない。
  行は `ui::BeginPropertyTable` の中に置き、見出しは `ui::SectionHeader`（テーブルの外）。
- 色を直書きしない。配色は `ui::ApplyTheme()` に集約する。例外は、ピンの型の色やノードのカテゴリの印の
  ような**意味を持つ色**だけ（`src/app/GraphPanel.cpp` の先頭にまとめてある）。
- アクセントは 1 色（`#96A3AD`）。選択の枠、変更の印に使う。
- 画面に出す文字は `ui::Tr("日本語", "English")` で両方書く。ノード名・ピンの型・チャンネル名のように
  英語のほうが通じる語は訳さない。
- 変わらない説明は「?」（`ui::SectionHeader(label, help)` / `ui::HelpMarker`）とツールチップへ。
  `ui::HintText` は「いまの状態」（選んでいない、空、など）にだけ使う。
- 文字が入る寸法は `ui::TextScaled()`、それ以外は `ui::Scaled()`。
- 見出し（`ui::SectionHeader`）は幅いっぱいの帯（`#272727`）に文字を置き、その下の行は一段字下げする。
- 項目名の列は、ウィンドウ全体で一番長い項目名に揃える（ウィンドウの中身の 4 割まで）。
  `ui::BeginPropertyTable` / `ui::PropertyLabel` が幅を測って次のフレームから揃える。
- 枠線と区画の境界は `#1C1C1C`（明度 11%）、太さは拡大率によらず 1 px（`ApplyTheme` の最後で戻す）。タブの帯の下の線も同じ色で描き重ねる
  （`ui::DrawDockTabBarBorders`、フレームの最後に `ImGuiLayer` が呼ぶ）。
- タブは選択中だけを板（`#3E3E3E`）で描く。非選択は板なし、ホバーで薄い板。選択中の上辺の線は引かない。

## ウィンドウとレイアウト

- ウィンドウ名は `"表示名###固定ID"`。DockBuilder からは `"###固定ID"` で引く。

  | パネル | 固定 ID | 既定の位置 |
  | --- | --- | --- |
  | 2D ビュー | `###View2D` | 上の左 |
  | 3D ビュー | `###View3D` | 上の右 |
  | グラフ | `###Graph` | 中央 |
  | パラメータ | `###Parameters` | 右 |
  | グラフ設定 | `###GraphSettings` | 右（タブ） |

- ドックスペースの名前（`SurfaceGraphDockSpace_vN`）は、パネルを足したり外したりしたら版を上げる。
- 既定のレイアウトは「ウィンドウ > レイアウトを初期化」で組み直せる。
- 「ウィンドウ > 設定」で、浮いたウィンドウ（ドックに収めない。terrain-graph と同じ）を開く。
  言語、Windows の表示スケールへの追従、拡大率（100〜200%）、文字サイズ（11〜28 px、既定 17）。
  拡大率を変えると、ウィンドウの描画領域を 1920×1080 × 拡大率 にし、ドックの分割も同じ比率で広げる
  （作業面積は変わらない）。文字サイズは拡大率と別に掛かり、ウィンドウの大きさは変えない。
  設定は `%LOCALAPPDATA%/surface-graph/settings.txt`。
  `--screenshot-ui` の起動は設定によらず 100%・17 px・日本語で撮る（`--ui-scale` / `--language` で指定できる）。
- ステータスバーは下端。解像度、ノード数、VRAM、GPU 時間、評価の状態、直近のログを出す。
  情報は 6 秒で消え、警告とエラーは次のメッセージまで残る。
- メニューは要求を積むだけにして、GPU の待機やグラフの差し替えはフレームの先頭で行う。
  ショートカットは必ずメニューにも表示する。
- 「ファイル > エクスポート...」（Ctrl+E）は、フォルダを選んでフレームの外で書き出す。
  設定は「ファイル > エクスポートの設定」のチェック項目（保存はしない）。
  プロジェクトでは、マテリアルの階層にいるときだけ使える（そのマテリアルを書き出す）。
- 「ファイル > アセットを書き出す...」（Ctrl+Shift+E）は、プロジェクトのアセット（`.glb` とテクスチャ一式）を書き出す。
- 「ファイル > 新規グラフ」（Ctrl+N）と「新規プロジェクト」（Ctrl+Shift+N）。「開く」は `.sgraph` と `.sgproj` の両方を出す。
  ファイルを指定せずに起動したときは、新しいプロジェクトから始まる。
- 未保存の確認ダイアログの警告マーク（`ui::WarningIcon`）は、行の高さの 1.1 倍（文字より少し大きい程度）。
- 「ファイル > 最近使ったファイル」は 10 件まで。項目はファイル名、ツールチップにフルパス。
  スクリーンショット用の起動（`--screenshot-ui`）では履歴に足さない。

## グラフのパネル

- ノード: 地 `#1A1A1A`（既定の枠も同じ色で見せない）、角丸 6、余白は上下左右とも 14。上から順に、見出し（カテゴリの色の
  小さな四角と名前）、ピンの行（入力は左、出力は右）、サムネイル（`ui::kNodeThumbnail` = 128、中央、
  1 つ目の出力）、そのノードの解像度と形式
  （`1024 × 1024  L16F`。文字は基準の 0.8 倍。Gray は `L16F`、Color は `RGBA16F`）。サムネイルは角丸で切り抜き、枠線は引かない
  （線が半ピクセル内側に乗り、拡大率によって絵の輪郭とずれて見えるため）。
- ピン: 丸は縁から余白の幅（14）ぶん内側に置き、リンクの端はノードの縁で止める（縁と丸の間は空けたまま）。
  ラベルは丸の中心から 12 離す。入力は繋がっていれば塗り、いなければ輪。縁から丸を経てラベルまでを
  掴める範囲にする。
  ピンの名前は言語の設定に関わらず英語で出す（`PinDef::label.english`）。
- ピンの型の色: Gray = 灰、Color = 水色 `(0.45, 0.78, 0.95)`、Value = 緑（まだ使っていない）。リンクも繋ぎ元の型の色。
- **選択と 2D ビューの対象は別**（terrain-graph と同じ）。選択はパラメータの対象、2D ビューの対象は
  出力ピンのクリックで決める。入力ピンの丸は繋がっていれば塗り、出力ピンの丸は 2D ビューに
  出している出力だけを塗る。
- 枠: 選択はアクセント色、2D ビューに出しているノードは水色 `(0.45, 0.78, 0.95)`、エラーは赤（太さ 2）。
- 2D ビュー: 上の操作列は操作だけ（チャンネル、出力、表示設定、全体）。グリッドとタイリングは「表示設定」のポップアップにまとめる（3D ビューと同じ作り）。ノード名・番号・解像度・形式は
  画像の領域の左下に薄く重ねる（`TextDisabled` の色に 1 px の影）。何も出していないときの案内は中央に重ねる。
- 2D ビューの「グリッド」: UV の整数（0, 1, 2…、タイルの境目）にだけ線を引き、画像の外側の領域いっぱいまで
  伸ばす。内側は分けない。色は付けず、原点を通る線（u = 0、v = 0）だけを濃くする。座標の数字は領域の
  上端（u）と左端（v）。原点は左上で v は下へ増える（シェーダの UV と同じ）。
  引いて線が 40 px 未満に詰まったら、2, 4, 8… おきに間引く。
- 2D ビューの「タイリング」: 1 枚目（UV の 0〜1）から右と下へ、見えている範囲いっぱいに画像を繰り返す
  （左と上へは描かない）。タイリング中は画像の枠を引かない（繋ぎ目に線があるように見えるため）。
- 背景は `#242424` に `#2B2B2B` の点の格子（terrain-graph と同じ）。エディタ自身の背景色は透明にし、`ed::Suspend()` の間に
  背景色と点を画面座標で描く。点は拡大率によらず 2 px で、引いたときは間隔を広げて間引く。
- ノードの位置はグラフモデルが持つ。エディタの表示位置と拡大率は保存しない。

## プロジェクト

プロジェクト（`.sgproj`。[decal-asset.md](decal-asset.md)）を開くと、同じパネルで 3 つの階層を行き来する。

| 階層 | グラフ | 2D ビュー | 3D ビュー | パラメータ | グラフ設定 |
| --- | --- | --- | --- | --- | --- |
| プロジェクト | メッシュ / マテリアル / アセット出力のノード | 選んだノードのレイヤーの UV（「真上」に切り替えると、真上から見たアセット） | アセット | 選んだノードの設定 | プロジェクトの名前、下地、アセットの状態 |
| メッシュ | メッシュグラフ | 表示中の出力の UV（「真上」に切り替えると、真上から見たパスかメッシュ） | アセット + 表示中の出力 + パスの線。パスの頂点を編集できる | ノードのパラメータ | （なし） |
| マテリアル | マテリアルグラフ（単体の `.sgraph` と同じ） | ノードの出力 | 形のプルダウンで、球 / 平面 / 角丸の立方体 / アセット | ノードのパラメータ | グラフの設定、区画の配置、タイルの実寸 |

- **パンくず**: プロジェクトでは、グラフのパネルの上端に 1 行置く（「repair_patch > sealant_edge」）。
  上の階層はボタンで、押すと戻る。いまの階層は文字だけ。外部参照のマテリアルは、名前の後ろにパスを添える。
- **メッシュの階層の 3D ビューは、既定でマテリアルなし**: メッシュの階層はマテリアルを割り当てる前の段階なので、
  アセットは描かず、表示中のノードのメッシュだけを、区画の確認用の絵（UV チェッカー）で出す。表示中のノードが
  メッシュを持たない（パスを見ている、何も選んでいない）ときは、このグラフのメッシュ出力を全部出す（パスを動かした結果が見える）。
  「表示設定 > マテリアルを貼って表示」を入れると、アセット全体を、繋いだマテリアルを貼って出す（表の「アセット + 表示中の出力」）。
  `--mesh-material` で、スクリーンショットの起動でも入れられる。
- **プロジェクトの階層で表示中の出力**: メッシュノードかマテリアルノードの**出力ピンをクリック**すると、3D ビューと
  2D ビューに、その時点の出力だけを出す（グラフのパネルの「出力ピンのクリックで 2D ビューの対象を選ぶ」と同じ作法）。
  **アセット出力ノードをクリックする**か、同じピンをもう一度クリックすると、アセット全体（最終結果）の表示へ戻る。選んだピンは、丸の外に水色 `(0.45, 0.78, 0.95)` の輪を足し、
  ノードの枠も同じ色（太さ 2）にする。丸の塗りは「繋がっている」の印のまま。3D ビューの操作列に
  「選んだ出力だけを表示中（アセット出力ノードをクリックで全体）」と出す。`--view-project-node <id>` で、スクリーンショットの起動でも選べる。
- **プロジェクトのノード**: 見た目はグラフのノードと同じ（地、角丸、余白、ピンの置き方）。
  マテリアルノードのサムネイルは Material Output の見本、メッシュノードのサムネイルは、出力のメッシュを全部重ねた
  真上からの図（下の「メッシュグラフのノード」と同じ描き方）。アセット出力はサムネイルを持たない。アセット出力の入力は、繋いだ順の番号と
  マテリアルの名前で、最後に空きの「+」を 1 本置く。
- **ピンの色**: Path = 琥珀 `(0.88, 0.72, 0.42)`、Mesh = 藤 `(0.76, 0.64, 0.88)`。マテリアルの付いたメッシュ
  （マテリアルノードの出力）は Value の緑を借りる。
- **メッシュグラフのノード**: サムネイルは、結果を真上から見た図（`graphui::DrawShapeThumbnail`）。テクスチャは作らず、
  ImGui の図形で描く。場所は常に 128 の正方形（形の縦横比で高さを変えない）で、全体が 84% に収まる縮尺にする。
  メッシュはピースの種類ごとの色（「真上」の図と同じ）で塗り、三角形の辺は引かない。パスはピンの色の線で、始点に丸を打つ。
  結果が無いとき（エラーなど）は面だけ。その下に、解像度の行の代わりに、中身の数（「8 点 閉」「頂点 128 三角形 64」
  「ピース 16」）を、基準の 0.8 倍の文字で出す。
- **2D ビューの操作列**（プロジェクトとメッシュの階層）: 「UV / 真上」のプルダウンと「全体」。既定は UV。
- **UV の表示**: テクスチャ（Material Output の見本）を UV の 0〜1 に置き、0〜1 の枠を白の細い線で引く。
  0〜1 の外へ繰り返したタイルは少し暗くする。区画は、ピースの種類の色の枠と名前。メッシュの UV は、ピースの色で
  薄く塗り（22%）、三角形の辺を明るめの同じ色で引く。マテリアルが無いときは、区画を同じ色で薄く塗って下に敷く。
  情報（出力の名前とマテリアルの名前、頂点と三角形の数、UV の範囲）は左下に薄く重ねる。
- **真上からのビュー**: X が右、Z が下。ピースの種類ごとに色を変える（灰 = 塗り、青 = 辺、橙 = 外角、赤紫 = 内角、
  緑 = 始端、黄 = 終端。CLI の `uv.png` と同じ）。頂点の `alpha` で透けさせ、三角形の辺を薄く重ねる。
  パスは琥珀の線に頂点の丸、始点だけ大きくする。1 m の格子を引き、原点を通る線だけを濃くする。
  情報（ノード名、頂点と三角形の数）は左下に薄く重ねる（2D ビューと同じ体裁）。
- **パスの編集**: メッシュグラフでパスノードを選ぶと、3D ビューと真上からのビューに制御点が出る。始点は四角、ほかは丸
  （半径 4、載せると 5、選ぶと 5.5 に白い輪）。曲線のときは、制御点を結ぶ折れ線（ガイド）を琥珀の 35% で重ねる。
  操作の一覧を右下に薄く出し、Ctrl を押している間は「足す」操作の一覧に切り替える。左下には、選んだ頂点の番号と座標
  （複数なら「N 点を選択」）。
- **選択の矩形**: アクセントの色で、塗り 15%、枠 90%。
- **移動ギズモ**: 選んだ頂点の重心に、X（赤）と Z（青）の矢印（長さ 64、線の太さ 2.5、矢じり 11 × 10）と、中央の四角
  （一辺 14、白の半透明に白い枠。頂点が 2 つ以上のとき）。色は `ui::TransformAxisColor`。載せた部品と掴んでいる部品は白くする。
  当たり判定は、軸の線から 8 px。
  操作は [decal-asset.md](decal-asset.md) の「パスの編集」。
- **3D ビューの重ね描き**: パスは琥珀の単色の細い帯。まだアセットに入っていない表示中の出力は、区画の確認用の絵
  （ピースの色分け）。操作列に「真上」のボタンを置く（アセットの表示のときだけ）。
- **3D ビューのワイヤーフレーム**: 「表示設定 > ワイヤーフレーム」（アセットの表示のとき）。メッシュはそのまま描き、
  その上に三角形の辺を黒（不透明度 85%）の 1 px の線で重ねる。パスの頂点とギズモは、その上に描く。
  `--wireframe` で、スクリーンショットの起動でも出せる。
- **3D ビューのアセット**: 「表示設定」のタイルと視差の行は出さない（UV はメッシュが決め、デカールでは視差を使わない）。
  UV チェッカーは確認用の絵になる（塗りには `assets/textures/uv_checker.png`、帯には区画ごとの色）。
  まだアセットに入っていない表示中の出力も、同じ絵で出す。アセットを組み立てられないときは、操作列に理由の 1 件目を赤で出す。
- **エラー**: メッシュグラフのエラー、読めないマテリアル、アセットの組み立てのエラーは、ノードの赤い枠と
  ツールチップ、パラメータ欄の赤い文で出す。
- スクリーンショットは `--enter-node <id>` で、プロジェクトのメッシュノードかマテリアルノードの中に入ってから撮れる。
  `--select-path-point <n>` で、パスの n 番目の頂点を選んだ状態にできる。

```
build/bin/Debug/surface_graph.exe --open graphs/decal/repair_patch.sgproj --screenshot-ui data/screenshots/project.png --screenshot-frame 60 --select-node 12
build/bin/Debug/surface_graph.exe --open graphs/decal/repair_patch.sgproj --screenshot-ui data/screenshots/mesh.png --screenshot-frame 60 --enter-node 10 --select-node 3
```

## 操作

| 操作 | 動作 |
| --- | --- |
| 空白で右クリック / Tab | 検索付きのノード追加メニュー |
| リンクを空白にドロップ | そのピンに繋げるノードだけのメニュー。選ぶと自動で繋がる |
| Delete | 選んだノード / リンクを消す |
| Ctrl+C / Ctrl+V / Ctrl+D | コピー / 貼り付け / 複製（クリップボードには JSON） |
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） | 元に戻す / やり直す |
| ノードをクリック | 選ぶ（パラメータに出る。2D ビューは変わらない） |
| 出力ピンをクリック | その出力を 2D ビューに表示 |
| ノードをダブルクリック | 1 つ目の出力を 2D ビューに表示 |
| プロジェクトのノードをダブルクリック | メッシュノード / マテリアルノードの中に入る |
| パンくずのプロジェクト名 | プロジェクトの階層へ戻る |
| 3D ビューか真上からのビューで、空をドラッグ | 矩形でパスの頂点を選ぶ（Shift で足す）。Shift + クリックでも足す / 外す |
| 3D ビューか真上からのビューで、頂点をドラッグ | 選んだ頂点を動かす（格子と、隣の頂点の X / Z に吸着。Shift で吸着しない） |
| 3D ビューか真上からのビューで、ギズモをドラッグ | 選んだ頂点を X か Z の軸に沿って動かす（中央の四角は平面） |
| 3D ビューか真上からのビューで、Ctrl + クリック | 頂点を足す（線の上なら挿入、反対の端なら閉じる） |
| 3D ビューか真上からのビューで、Delete / 右クリック | 頂点を消す / メニュー（挿入、閉じる・開く、向きを反転） |
| 3D ビューの「真上」 | 真上から見る向きにする（F で元の向きへ戻る） |
| メッシュグラフで出力ピンをクリック | その出力を 2D ビュー（UV）と 3D ビューに出す（メッシュ出力に繋いでいなくてもよい） |
| プロジェクトで、マテリアルの出力をアセット出力へ繋ぐ | 空き（+）へ落とすと末尾に足す。繋がっているピンへ落とすと、そのレイヤーを置き換える |
| A | グラフ全体を表示 |
| グラフの右上のボタン | グラフを整列（左から右へ列に並べる） |
| 中ボタンドラッグ / ホイール | キャンバスの移動 / 拡大縮小 |
| パラメータの行で右クリック | グラフ入力として公開 |
| 3D ビューでドラッグ / L + ドラッグ / 中ボタンドラッグ / ホイール | 視点を回す / ライトを回す（ギズモが出る）/ パン / 近づく・離れる |
| 3D ビューで Alt + 左 / 中 / 右ボタンドラッグ | 視点を回す / パン / 近づく・離れる（DCC ツールと同じ割り当て。右か上へ動かすと近づく）。**メッシュグラフの中では、視点を回す操作は Alt + 左ドラッグだけ**（Alt なしの左ボタンは頂点の編集に空ける） |
| 3D ビューで F | 視点を戻す（向き・距離・パン。terrain-graph のビューポートと同じキー） |
| スライダーを Ctrl+クリック | 値を直接入力 |

ショートカットは、キャンバスに載っていて文字入力中でないときだけ効く。

## アンドゥ

- グラフ全体のスナップショットを積む（最大 100 手）。プロジェクトでは、プロジェクト全体
  （プロジェクトのグラフ、メッシュグラフ、マテリアルグラフ。外部参照のものも含む）のスナップショットを積む。
- 同じ部品を掴み続けている間（スライダーのドラッグ）は 1 手にまとめる。
- **ノードの移動はアンドゥの対象にしない。** 位置は保存されるが、元に戻す対象にはならない。
- 例外は**整列**。まとめて動くので、1 手として積む（Ctrl+Z で整列の前に戻る）。

## ノードのメモ

terrain-graph と同じ。どの種類のノードにも、置いた意図などのメモ（複数行の文字列、`Node::note`）を持たせる。

- パラメータ欄の先頭に `ui::PropertyTextMultiline` の「メモ」を 3 行の高さで置く。確定は欄外のクリック
  （Enter は改行）で、確定するとアンドゥの 1 手になる。評価には使わない（ハッシュに入れない）。
- ノードの見出しの右に、メモがあることを示す小さな紙の印を描く。
- 「ウィンドウ > 設定 > グラフ > メモを表示」（既定オン、`settings.txt` に保存）がオンのとき、メモの先頭を
  ノードの**下端のすぐ下**に、ノードと同じ幅の吹き出し（`PopupBg` の下地、`Border` の枠、`TextDisabled` の文字）で
  最大 3 行出し、収まらない分は「…」にする。**ノードの中には描かない**（メモの有無でノードの高さが変わると
  配置が崩れるため）。折り返しは文字ごとに幅を測って自前で行う（日本語の長い文で ImGui の折り返しがずれるため）。
- 印か省略した吹き出しに載せると、全文をツールチップ（幅 360）で出す。
- 整列は吹き出しの高さも含めてノードを並べる。

## グラフに重ねるボタン

- グラフの右上に、図形のボタンを置く（いまは整列だけ）。地はメニューバーと同じ暗さ（`MenuBarBg`）。字形ではなく図形で描き（`ui::ArrangeIconButton`）、
  ホバーで説明を出す。
- キャンバスに重ねるので、子ウィンドウの中に置く（同じウィンドウに置くと、クリックがキャンバスへ抜ける）。
- 整列は `graph::ArrangeColumns`（`src/graph/GraphLayout.h`）。Material Output を右端に、上流を左の列へ並べる。

## 確認のしかた

UI を変えたら、スクリーンショットを 1 枚撮って目で見る。

```
build/bin/Debug/surface_graph.exe --open graphs/brick.sgraph --screenshot-ui data/screenshots/editor.png --screenshot-frame 40 --select-node 2
```

- `--screenshot-ui` はバックバッファを読み戻すので、ウィンドウが隠れていても欠けない。
  評価が終わるまで待ってから撮り、撮ったら終了する。
- `--select-node <id>` で、撮る前に選ぶノードを指定できる。
- `--preview-shape sphere|plane` で、3D ビューの形を指定できる。
- `--ui-scale 1.5` のように、UI の拡大率を指定できる。
- `--show-light-gizmo` で、3D ビューのライトのギズモを出したまま撮れる。
- マウス操作を伴う変更は、スクリーンショットでは確かめられない。確かめていないときは、そう報告する。
